# Stage 3 真机最终验收单

基线版本：**北北计算器 0.3.16 Release**  
Release tag：`beibei-0.3.16`  
Application ID：`com.beibei.calculator`

> 只使用 0.3.16 Release 做最终验收，不用旧 Debug APK 判断 Stage 3 是否通过。

## 1. 普通光标与选区

输入 `123456789`：

- 点击 `4/5` 附近，光标应移动到点击位置附近；
- 在表达式上水平左右滑动，光标应连续移动，不乱跳；
- 长按选中一段后，左右抓手都能拖动；
- 松手后选区保留；
- 再点已有选区能打开复制/粘贴菜单。

## 2. 分数

输入一个分数，例如 `12/34`（使用分数模板）：

- 点击分子应进入分子槽；
- 点击分母应进入分母槽；
- `↑/↓` 能在分子与分母之间切换；
- DEL 只删除当前槽内容，不应拆掉分数结构线；
- 分子或分母删空后仍可继续输入。

## 3. 幂

输入 `2^35`：

- 点击底数区域应进入底数；
- 点击指数区域应进入指数；
- `↑/↓` 能在底数与指数之间切换；
- 指数内 DEL 不应把 `^` 结构单独删坏。

## 4. 根号 / n 次根

分别输入平方根和 n 次根：

- 平方根点击被开方数应进入根号内容；
- n 次根点击左上根指数应进入 `ROOT_INDEX`；
- 点击被开方数应进入 `ROOT_CONTENT`；
- `↑/↓` 在根指数与内容间切换；
- DEL 不应拆坏根号模板、逗号或闭括号。

## 5. 函数参数精细选择

输入 `sin(30)`：

- 长按/拖动应能只选择 `30`；
- 选中参数后直接输入 `45`，应得到 `sin(45)`；
- 选中参数后粘贴也应只替换参数。

输入 `sum(x,1,3)`：

- 单独拖选 `1` 应只选第二个参数；
- 拖选跨过参数结构逗号时，应自动吸附为完整函数，不留下破坏结构的半截函数。

## 6. 兼容行为回归

快速复验：

- AC；
- 长按数字连续输入；
- 长按 DEL 连续删除；
- 复制 / 粘贴；
- `56²` 复制粘贴后仍能正确计算；
- 空编辑器长按仍能出现粘贴；
- 结果区域长按能复制 Ans；
- 使用 Ans 后，完成计算时能看到展开后的上一计算过程；
- 历史前后切换正常。

## 7. 双变量统计

进入双变量统计并做一组简单数据计算：

- 页面能正常进入；
- 结果能正常生成；
- 不闪退。

这项用于确认 0.3.16 的 `TwoVariableResults` R8 根因修复在正式 Release 真机上正常。
