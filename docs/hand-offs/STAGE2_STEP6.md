## 本步完成

- 显示区长按进入选区模式，并提供长按触感反馈。
- 长按后横向拖动可移动选区焦点，不再要求先按 SHIFT。
- 拖动过程中只在边界变化时提供短触感，避免连续滑动震动过密。
- 松开后打开复制菜单，可继续复制选区、计算过程、计算结果或粘贴。
- 触摸选区仍遵守语义边界：函数、幂、分数不会被拆成无法计算的半结构。
- 复制导出使用 evaluator source，避免把 `a/b`、`√(` 等显示标签直接粘贴出去。

## 当前人工验收

需要在 MuMu 或真机上确认：

1. 长按后继续拖动时，选区高亮和两端边界是否符合预期。
2. 快速滑动、反向拖动、拖到表达式首尾是否稳定。
3. 长按触感与边界变化触感是否自然。
4. 复制选区后从粘贴菜单再次插入，内容是否保持可计算。
5. 多指同时操作时不会误触键盘或破坏选区。
