## 2. 函数表：结构化输入 + TABLE 结果

### 单函数

- [ ] HOME → 函数表 → `f(x)`；看到字段 `f(x) / 开始 / 结束 / 步长`。
- [ ] 输入 `x^2, 0, 10, 1`，计算后显示真正表格而不是摘要文本。
- [ ] 表头应为 `x / f(x)`；首行 `0 / 0`，末行应能翻到 `10 / 100`。
- [ ] `↑/↓` 每次滚动一行；`Page↑/Page↓` 每次翻一页；行范围与滚动条同步。

### 双函数

- [ ] 进入 `f(x), g(x)`；看到 `f(x) / g(x) / 开始 / 结束 / 步长`。
- [ ] 输入 `x, x+10, 1, 6, 1`；表头为 `x / f(x) / g(x)`。
- [ ] 翻页过程中三列数据始终同一行对齐，不丢列、不串行。
- [ ] BACK 从结果返回输入后，之前的字段内容仍保留。

## 3. 不等式：二 / 三 / 四次闭环

每一种都检查一次：

- [ ] 二次显示：关系 + 3 个系数。
- [ ] 三次显示：关系 + 4 个系数。
- [ ] 四次显示：关系 + 5 个系数。
- [ ] 关系格不能输入普通数字文本；方向键循环 `> / < / ≥ / ≤`，DEL 恢复默认关系。
- [ ] 输入不完整时点“计算”，焦点应跳到第一处空白；输入格式错误时跳到第一处错误格。
- [ ] 至少各完成一组可计算示例，结果与原不等式引擎一致。

建议快速样例：二次 `x²-1>0`；三次 `x³-x>0`；四次 `x⁴-1≤0`。

## 4. 比例：标签输入 + 旧逗号兼容

- [ ] `A:B=X:D` 显示三个已知量标签 `A / B / D`；输入 `2,4,10` 得 `X=5`。
- [ ] `A:B=C:X` 显示 `A / B / C`；输入 `2,4,3` 得 `X=6`。
- [ ] 结果以结构化 `X` 项显示，不退回只有一行不可解析文本。
- [ ] 在第一个比例输入格直接按逗号，可回到历史逗号输入方式；继续输入完整旧格式仍能计算。

## 6. 必测：调阶 / 调元数时数据不能换含义

这是本轮静态审计新发现并已修复的重点。

### 多项式

- [ ] 进入多项式方程，二次系数依次输入 `a2=1, a1=2, a0=-3`。
- [ ] 点“提高阶数”升到三次：应新增一个空白 `a3`；原来的 `1 / 2 / -3` 必须仍对应 `a2 / a1 / a0`，不能整体上移成 `a3 / a2 / a1`。
- [ ] 给新 `a3` 输入任意值，再点“降低阶数”：只丢弃最高阶 `a3`；`a2=1, a1=2, a0=-3` 必须保留。

### 联立方程

- [ ] 二元方程输入第一行 `1,1 | 5`，第二行 `2,-1 | 1`。
- [ ] 点“增加元数”升到三元：原 `x1/x2` 系数保持原位，新 `x3` 列为空；常数 `5 / 1` 必须移动到新的最右 `b` 列，不能落进 `x3` 列。
- [ ] 再点“减少元数”回二元：原 `x1/x2` 和 `b` 完整恢复。
- [ ] 用物理快捷方式 `SHIFT + ↑/↓` 再重复一次，行为应与触摸操作条完全一致。
