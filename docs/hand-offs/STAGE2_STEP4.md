# Stage 2 第 4 步交接：语义选区核心

完成日期：2026-09-16

## 本步完成

- 核心状态机新增语义选区锚点和焦点。
- `SHIFT+LEFT` / `SHIFT+RIGHT` 可按 token 语义范围扩展选区。
- 普通左右移动会先折叠选区，再继续移动。
- DEL 在有选区时删除整个选区。
- 输入新按键时替换选区，而不是把字符插入选区中间。
- 核心状态向 Android 暴露 `hasSelection`、`selectionStart`、`selectionEnd`。
- 选区 token 在自然表达式树中带有选中标记，渲染层会显示高亮。
- 长按复制菜单在有选区时新增“复制选区”。
- 选区文本由核心语义 token 导出，不从屏幕绘制字符串反推。
