# Stage 5 接力状态：应用输入与结果工作流

更新日期：2026-09-17

仓库：`beiming183-cloud/beibei-calculator`

工作分支：`stage5/application-workflows`

基线：`main@66b21ab77609574189ef578b39a2499e04ee6655`（Stage 4 PR #4 已按用户授权合并；0.3.17 真机验收延后集中进行）

## 目标

Stage 4 已经把统计、方程、矩阵、向量的结果升级为 core-owned 结构化协议。Stage 5 继续处理输入侧：逐步替换“进入模式后输入一串逗号参数”的临时桥接，让 core 明确定义工作流需要的字段、数据形状和页面状态，Android 只负责展示与触摸交互。

兼容原则：

- 不改数值算法与既有结果协议；
- 旧逗号输入路径继续保留为兼容回退，直到对应专用输入页完成；
- Stage 3 语义编辑、复制粘贴、Ans、历史不得回归；
- `com.beibei.calculator` 与长期 Release 签名链不得改变；
- 0.3.17 真机排版检查延后，不阻塞 Stage 5 主线。

## Step 1：core-owned 输入规格协议（in progress）

目标：新增不可变 `WorkflowSpec / FieldSpec`，由 core 描述应用命令的标题、输入布局、字段标签、是否重复、最小/最大行列或参数数目。第一批覆盖统计、方程、矩阵和向量，并补 core regression。

## Step 2：统计专用数据输入状态

目标：一元统计用单列数据、双变量/回归用双列数据，支持行新增/删除、方向键移动与 EXE 计算，同时保留旧逗号输入兼容入口。

## Step 3：方程专用系数输入状态

目标：多项式系数、2–4 元联立方程系数、SOLVE 表达式/初值由结构化字段承载。

## Step 4：矩阵 / 向量专用输入状态

目标：矩阵先选尺寸再编辑网格；向量按 2D/3D 和单/双向量编辑分量。

## Step 5：Android 专用输入页与集中回归

目标：Android 根据 core workflow state 渲染统计表格、系数表、矩阵/向量输入页；完成后再与 0.3.17 遗留真机检查一起集中验收。
