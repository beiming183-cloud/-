## Stage 2 已完成并通过的重点

1. EXE 只自动补齐缺失右括号；多余右括号、残缺运算符等非法表达式仍报错。
2. 长结果不再使用 `...` 截断；超长数值使用自然科学计数形式展示。
3. 手机式自由选区：长按进入选区、松手保留；左右边界可独立拖动；点击选区进入剪贴板菜单。
4. 函数、分数、幂等结构继续按语义单元吸附，避免拖选或 DEL 拆坏结构。
5. 选区抓手扩大实际触摸热区，视觉大小不变；短选区按距离判断左右边界。
6. 左右滑动和直接点击表达式均可移动光标。
7. 一根手指保持按下、另一根手指继续操作时未发现明显多指冲突。
8. 空表达式可直接长按打开粘贴入口。
9. 剪贴板粘贴进入核心语义解析链，支持 `56²` / `56^2`、`√(9)`、`π/2`、`i^2`、`Ans+1`、`1E3`；未知字符整段拒绝，不允许静默丢字符后改变数学含义。
10. 进入剪贴板菜单以及执行复制/粘贴动作均补齐触感反馈。
11. 结果区域可复制 Ans；连续计算时用于核查的过程会展开上一条 Ans 来源。
12. Ans 过程展开是递归的，例如 `2+3` → `(2+3)×2` → `((2+3)×2)+1`，内部 evaluator 仍保持 Ans token，不改变精度和运算语义。
13. 左侧 ON / Home / Settings / Back 四键整体放大；方向键按左右模块实际边界动态居中。
14. HOME 改为带留白的圆角应用卡片，减少硬网格感。
15. GitHub Actions 继续执行完整 `:core:check` 与 Android Debug APK 构建。

## 下一阶段计划：Stage 3 语义编辑器

Stage 2 已通过真机验收，下一阶段不再继续堆触摸补丁，优先解决当前架构中最重要的剩余问题：**光标仍是 token 下标，而不是真正的语义编辑位置。**

Stage 3 建议按以下顺序进行：

1. **建立语义位置模型**
   - 新增类似 `CursorPath(root, childIndex, slot)` 的结构；
   - 保留旧 token index 作为兼容层，不一次性推倒现有代码。
2. **分数内部移动**
   - 可进入分子、分母；
   - 左右移动与上下切换有明确规则；
   - DEL 不拆坏分数结构。
3. **幂、根号和函数内部移动**
   - 可进入指数、根号内容、函数参数；
   - 左右/上下移动按数学结构跳转，而不是按字符串宽度猜位置。
4. **统一选区与删除协议**
   - 选区锚点使用语义位置；
   - 复制、替换、删除继续保证结构完整。
5. **回归兼容**
   - AC、Ans、历史、复制粘贴、长按重复、真机手势保持现状；
   - 每增加一种结构，先补核心回归再接 Android 渲染。
6. **Stage 3 完成后**
   - 再进入统计、方程、矩阵、向量等应用模式的统一结果协议和专用界面补齐。
