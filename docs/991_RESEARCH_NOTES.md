# 991CN CW 交互研究与 0.3.1 决策

本轮只针对 991 配置。研究依据是用户提供的中文说明书和公开的产品资料，
实现代码、图标、字体与 APK 资源均为本项目独立编写。

## 观察到的公开交互规则

- 说明书第 12–16 页：HOME 用图标选择应用，方向键移动，OK/EXE 确认，
  左键或 Back 返回；菜单有下级时进入下级，AC 关闭菜单。
- 说明书第 13–14 页：SHIFT 是一次性修饰键，7 的第二功能是 π；物理
  EXE 与表达式关系符 `=` 不是同一个意图。
- 中国官网产品页：屏幕尺寸比例为 192×63，最高六行，四级灰度，当前
  输入位置用深色强调；方向键是主要操作中心，HOME 同屏约六个图标。
- 官网的实机图显示：屏幕后有独立控制甲板，再有变量/功能/目录/工具
  上下文键；上方两行是六个紧凑数学键，数字区是五列。

## 本次代码改动

1. `PhysicalKeyLayout` 单独拥有 991 的按键语义、主/SHIFT 标记和命中矩形；
   `CalculatorView` 只负责绘制和把触摸映射为 `CnCwKey`。
2. 去掉窄小的七按钮控制条，改为电源/主页/设置/返回、中央方向键+OK、
   右侧翻页键和五个上下文键；数学区改为六键函数行+五键数字行。
3. 移除 UI 中独立 π 键；`SHIFT+7` 输入 π，`SHIFT+Format` 输入 Ans，
   `SHIFT+` 加/减分别输入 nPr/nCr。
4. LCD 指示带变薄，表达式字号和结果字号增大，选中项使用深色块，HOME
   使用 3×2 分页视窗；机身与按键采用原创低饱和薄荷/灰度配色。
5. HOME 的设置键现在进入设置根菜单；复位先显示确认页，系统设置的“关于”
   才进入计算器 ID；菜单族切换不会把旧菜单错误压回返回栈。
6. Gradle 只生成 `cn991`，版本升为 0.3.1；Distribution/Spreadsheet 不在
   本轮 991 产品面上。

## 仍未宣称 1:1 的部分

统计表格、矩阵/向量编辑器、方程系数页、完整 MathI/MathO 模板、精确根式
和所有设置单选子页仍是下一阶段工作。当前保留的逗号桥接是可测试的过渡层，
不能把它描述成完整实体机功能。
